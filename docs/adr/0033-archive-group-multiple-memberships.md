# 压缩包分组采用平级多成员引用与追加合集关系

2026-11-09，用户确认分组主要用于组织视频合集、图片合集及二者关联，因此改为平级独立配置，同一文件可加入多个分组。该目标替代 ADR 0032 中的单分组归属及父子配置继承；物理源文件与虚拟整理分离的边界继续保留。

同一媒体复用一份正式记录，首次成功入库确定元数据，后续分组提交只追加关系；同次提交存在元数据冲突时由管理员选择来源。相比每组创建独立媒体记录，该方案避免重复媒体，但要求分开表达媒体入库状态与各组关系应用状态。分组选定的两类合集在显式入库时全部两两追加关联，保留既有关系，关联影响整个合集的成员；拖入分组只保存草稿。旧批次转换、删除语义及执行中编辑边界尚待后续访谈确认，本文记录目标决策，不表示已实现。
