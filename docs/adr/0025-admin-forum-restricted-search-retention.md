# 管理端论坛资源纳入受限帖子并保护待检查记录

> 状态：已接受（2026-08-14）

现有资源感知保留策略会清理首次入库超过 30 天且没有附件或 ED2K 的全部帖子，这既可能删除仍在等待检查或重试的活跃记录，也会让管理员无法继续查找受限帖子。

项目决定让当前状态为 `pending` 或 `restricted` 的帖子不参与年龄清理，不论筛选结论及是否已有资源；保留豁免只跟随当前状态，不记录“曾经受限”，不恢复已经清理的历史记录，普通旧帖仍按资源感知规则由有效 `discover` 请求触发清理。管理端论坛资源列表永久展示 `restricted + included`，以“受限”标记与普通记录区分；`restricted + excluded` 只保留、不展示。

同一列表增加服务端标题搜索：搜索词最多 200 个字符，按去除首尾空白后的大小写不敏感字面子串匹配，`%` 与 `_` 不作为通配符，结果继续按发现时间倒序。搜索使用显式提交，清空后恢复完整列表，不持久化到 URL 或浏览器；首版不引入 `pg_trgm` 或其它搜索索引，待真实查询性能证明有必要时再调整。

本决策取代 ADR-0023 中“所有超过 30 天且无资源的记录均可清理”的范围，并取代 ADR-0021 中排除 `restricted`、不提供搜索及受限记录沿用普通年龄展示边界的相关决策。
