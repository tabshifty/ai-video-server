# 管理端中国行政区划地图采用可追溯离线快照

管理端中国行政区划地图以固定版本的 OpenStreetMap 行政边界为几何来源，并结合可追溯的公开中文行政区目录离线生成按父级拆分的静态 GeoJSON 与搜索索引。生成数据保留 ODbL 归属、来源和相同方式共享要求，业务代码继续沿用仓库原有许可证；页面运行时不调用第三方地图接口。这样选择是因为常见现成县级数据无法同时满足完整中国范围、中文名称、县级边界、数据新鲜度和明确再分发许可。

每个区域使用仓库规范化的稳定 `region_code` 作为区划标识，原始来源编码及来源名称另作可选字段，避免把大陆与港澳台的混合编码冒充统一国家标准。快照只能人工触发升级；发布前必须通过省级范围与港澳台存在、父子闭合、标识唯一、中文名完整、几何有效和末级可达性门禁，任何缺失都会终止生成。

## 未采用的方案

- 不直接打包许可或离线再分发条款不明确的 DataV 与无许可证 GitHub 数据。
- 不采用代表年份为 2017、英文名称且缺少行政区编码的 `geoBoundaries` 作为唯一来源。
- 不在构建或页面运行时自动联网拉取边界，避免同一代码提交产生不同地图。
