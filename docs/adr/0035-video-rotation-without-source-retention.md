# 视频方向修正成功后不保留旧文件

需求讨论已确认：管理员逐条发起服务端永久旋转，所有播放端和下载修正文件生效。用户明确以节省硬盘空间为优先，修正成功后删除被替代的旧文件，不长期保留原片或历史版本供撤销；因此无法恢复原文件副本。方向修正优先修改元数据并直拷媒体流，纯元数据操作可再次反向调整标记；需要重新编码时提交前明确提示并取得确认，已发生的编码损失无法通过反向旋转恢复。

清理必须在新文件校验及播放切换成功后进行；失败时保留旧文件并清理半成品。处理期间仍需要临时输出空间，空间不足应拒绝或终止处理，不能提前删除唯一可用文件。仅清理该视频独占且由服务端管理的文件，不由此推导删除共享导入资源或 115 云端源文件的权限。首期仍排除杜比视界源；两条处理路径共用该清理策略，当前未实施。
