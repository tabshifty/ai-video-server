## 目的地

形成一份可直接交付实施的 TV 长视频独立频道页 UI 重构决策：覆盖电影、电视剧与 18+，以成熟 OTT 产品的内容发现体验为参考。

## 备注

- 本地图只规划 UI 与遥控器浏览体验；首屏优先展示最近播放、最新添加与相似内容。
- 先以现有客户端和接口数据为边界，不新增服务端推荐算法、接口或内容管理能力。
- 页面实现使用 Jetpack Compose；后续视觉决策参考已生成的 TV 流媒体暗色、视频优先设计建议，但不复制任何单一产品的品牌元素。
- 本地 Markdown 充当 issue tracker：子票据位于同级 `tickets/` 目录，frontmatter 中的 `parent`、`status`、`assignee` 和 `blocked_by` 表示父子、状态、认领与阻塞关系。

## 尚未明确

- 海报与横幅资源不足时的视觉降级策略，以及各频道可接受的卡片密度和首屏行数。
- 成熟 OTT 模式中哪些信息可由现有数据可靠呈现，哪些应在首期隐藏而非伪造。
- 频道页刷新、加载、空态和失败态在统一视觉语言中的表现。

## 不在范围内

- 短视频入口、长视频详情页、电影/剧集/18+ 播放器及其播放行为。
- 服务端推荐算法、新 API、内容入库规则、个性化数据采集和后台管理功能。
- 复制 Netflix、Apple TV、Bilibili TV 或其他产品的品牌、文案和专有视觉资产。
