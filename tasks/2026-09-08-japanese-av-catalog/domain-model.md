# 日本 AV 元数据目录领域模型草案

> 状态：提议中。模型按“外部完整目录独立于本地视频”设计，等待用户确认产品范围。

## 核心术语

### 目录发行条目

目录中的核心聚合，表达一次可识别发行，而不是一个本地文件。它拥有内部 UUID，可包含规范化番号、原始标题、中文标题、发行日期、时长、片商、厂牌、系列、简介和合并后的分类、演员信息。

首期不额外抽象“作品”。重发、剪辑版、合集和同内容不同番号先表达为不同发行条目，并通过关系或人工合并处理；只有真实需求证明需要跨发行作品层时再新增。

### 来源条目

某个外部来源对一次发行的记录，唯一键为 `(source_id, external_id)`。保存来源 URL、来源番号、原始字段、内容指纹、首次发现时间、最后成功抓取时间和来源状态。一个来源条目只能归属一个目录发行条目。

来源条目是可追溯事实，不能因为合并视图变化而丢失。来源下架时标记状态，不直接删除目录发行条目。

### 字段事实

来源条目对某个字段给出的原始值及规范化值，例如某来源声称发行日期为 `2026-09-01`。字段事实携带来源、抓取时间和内容指纹，不直接等同于用户最终看到的字段。

首期可把同一来源条目的字段事实保存为版本化 JSONB 快照；需要跨时间查询或字段级审计时再拆成关系表。无论物理实现如何，接口必须保留字段级溯源能力。

### 合并字段

目录发行条目当前展示的值。选择顺序暂定为：有效人工覆盖高于已批准来源；来源之间按字段级优先级；同一来源取最新成功事实。合并过程必须记录选择依据，不能覆盖或删除原始字段事实。

### 人工覆盖

管理员明确确认的字段值、原因、操作者和时间。人工覆盖可撤销；撤销后重新从现有来源事实计算合并字段。后续采集不得静默覆盖有效人工值。

### 目录人物与来源人物身份

目录人物表达系统内归并后的演员或导演；来源人物身份表达某来源中的人物 ID、名称和资料 URL。名称和别名只能生成归并候选，不能单独作为自动合并的充分条件。

现有 `actors` 服务于本地媒体展示。首期优先新增来源人物身份，再由显式关联连接现有演员，避免目录抓取因同名或改名污染本地演员。

### 图片资产

封面、缩略图或样例图片的来源记录。至少保存来源 URL、类型、抓取时间、版权或缓存策略、内容哈希和本地存储状态。没有明确图片保存许可时只保存允许保留的引用信息，不下载、不代理、不裁剪。

### 本地视频关联

连接目录发行条目与现有 `videos` 的显式关系，记录关联方式、置信度、状态、确认人和时间。番号相等只能创建自动关联候选；存在同番号多版本或无码内容时必须人工确认。

一个本地视频最多有一个当前主目录关联，但历史关联需要保留；一个目录发行条目可以关联多个本地文件，例如不同画质或剪辑版本。

### 采集源、采集游标与采集运行

- 采集源：来源配置、准入状态、限速、并发、认证引用和暂停原因。
- 采集游标：来源目录发现的可持久化进度，例如最后更新时间和稳定分页令牌；不能只保存进程内页码。
- 采集运行：一次发现或回查任务，记录起止时间、游标范围、请求数、新增数、变更数、失败数和停止原因。

## 身份与去重规则

1. `(source_id, external_id)` 是来源内强唯一键。
2. 规范化番号是跨来源高价值匹配键，但不是数据库全局唯一键。
3. 番号、发行日期、片商和标题共同生成自动归并评分；低置信或冲突结果进入审核队列。
4. 自动归并只追加来源条目关系，不删除任何原始事实。
5. 人工合并和拆分必须可审计、可回滚，并重新计算受影响的合并字段与本地视频关联候选。

## 建议状态机

```text
来源条目：discovered -> fetched -> normalized -> matched
                                      |          -> review_required
                                      -> rejected

采集运行：queued -> running -> succeeded
                         |    -> partial
                         -> failed

准入状态：candidate -> pending_evidence -> approved
                                  |       -> rejected
                                  -> rejected

运行状态：idle -> running -> idle
             |       |     -> error
             -> paused <----+
```

`partial` 表示运行已保存部分确定结果，但因限速、来源故障或主动停止未完成当前窗口；下一次必须从持久化游标安全续跑。

准入状态表达“是否有权采集”，运行状态表达“当前能否运行”。网络故障、熔断或人工暂停不删除批准记录；条款变化则同时暂停运行并把准入退回 `pending_evidence`。

## 暂不创建的万能抽象

- 不创建一个同时容纳视频、演员、厂牌和分类的通用 `entities` 表。
- 不把所有字段只塞入无法约束和查询的单个 JSONB 文档。
- 不把来源优先级做成全局单一排名；标题、简介、发行日期、演员和图片可以有不同权威来源。
- 不把网络抓取结果直接写进现有 `videos.metadata` 作为长期目录数据库。
